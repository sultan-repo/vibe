# Vibe v4.12.0

Install Vibe in Claude Code or use the Codex installer, open your project and describe the task. Both use the shared workflows and their own native agent capabilities.

The Codex installer makes the routing rules available on the first prompt in a fresh session. Executable hooks follow Codex's trust settings. On the first authorized edit, Vibe keeps shared policy in AGENTS.md and imports it from the project's Claude instructions. Existing owner rules are preserved.
